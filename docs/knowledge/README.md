# Grow knowledge base

Operational know-how for the Grow systems (GrowSales dashboard, syncs, ISP lead pipeline, payroll, task bots), converted from the previous owner's (Josh's) Claude memory as of Oct 1 2026 and updated through Oct 21 2026 (his last day) from the memory files, `GrowSales/docs/audit-2026-10-14.md` and the live Mac. Paths are relative to the handoff repo root (`GrowSales/`, `WolfOffice/` (task bots), `RepText/`); `/Users/joshuawolfer/...` paths from the old Mac don't exist here. Facts carry dates; when something looks off, trust the code and live data over these notes and update the note.

Read **user-preferences.md**, **repo-and-deploy.md** and **gotchas.md** before your first change. Then read the topic file for the task.

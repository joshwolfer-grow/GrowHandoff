## Canva MCP limits and workarounds

- Some images in Grow decks are owned outside the team (old "Night Presentation" assets, e.g. `MAG38YIBmvo` profit share chart, `MAHK_j3FjQM` ISP comp grid, `MAHOuR3-bNI` Sequifi screenshot): `get-assets` / `insert_fill` return permission_denied. Duplicating the design keeps the same mediaId; export then `upload-asset-from-url` fails (signed export URLs). What works: download and re-upload the file manually into Canva Uploads (new asset id), or rebuild natively. Accessible: pay scale tables `MAHKIx-gPAs` (rookie), `MAHKI-uPrvQ` (vet), per-deck GROW logos.
- `add_text` lands at 16px black default font: always follow with `format_text` (white, size). Font family can't be set via MCP.
- `get-design-content` was not exposed; text extraction works via `export-design` (pptx/pdf) + local XML/pypdf.
- Canva docs (responsive pages): the only text edit that works is `find_and_replace_text` on the PAGE locator id, run by run. Replaced text keeps the formatting of the run where the match STARTS (a cross-run find starting on "\n" or a bold run drags formatting onto the next heading). Duplicate strings are replaced everywhere: do the copy with unique context first. Linked runs: replace link text with a space, fold the space into the neighbouring run. MCP cannot insert images into a doc page (`insert_fill` rejected; `update_fill` on an existing image slot works). Images were placed through the Chrome extension: upload into Canva Uploads (files under the session working folder), Cmd+F to the target line, click after the last character, Return (twice to exit a bullet), click the thumbnail by file name via `find` (Uploads search ranks fuzzily). Chrome must be signed into the growmarketing.biz Canva account. No delete via MCP.
